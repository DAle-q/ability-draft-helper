# Подтверждённые иконки

Ручной выбор сохраняет здесь PNG 64×64 с одной иконкой и запись в `index.json`.
Это обучающие примеры, а не фиксированная привязка к месту на экране. Файлы
можно коммитить и переносить на другой компьютер. Полные скриншоты не нужны.

Повторный выбор на том же изображении заменяет название у того же образца.
Кнопка «Забыть этот образец» убирает соответствие из индекса; старый PNG
сохраняется, чтобы удаление было обратимым через Git.
