# Ability Draft Helper

Локальное приложение: открыть скриншот драфта Dota 2, получить общий винрейт около иконок, исправить сомнительные совпадения и сохранить PNG. Изображения никуда не отправляются.

## Запуск

На текущем компьютере:

```sh
./start.sh
```

1. Нажмите **Открыть скриншот…** и выберите изображение.
2. Подождите распознавания. **?** означает неподтверждённое совпадение.
3. Нажмите на иконку для проверки: введите английское название, выберите строку и нажмите **Выбрать**.
4. Нажмите **Сохранить PNG…**.

Можно передать путь к изображению: `./start.sh /path/to/screenshot.png`.

На другой машине нужен Python 3.10+ с Tkinter и пакетами из `requirements.txt`. Скрипт запуска использует уже установленный runtime Codex, если он доступен; иначе системный Python. Сам ничего не устанавливает.

## Ограничения первой версии

- Пока поддерживается полный экран драфта с геометрией как у тестового изображения (2783×1383, примерно 2:1), включая пропорционально уменьшенные копии. Другие расположения сетки и обрезанные скриншоты не поддерживаются.
- Это сопоставление изображений, а не гарантированное распознавание. Есть ручное исправление. Портреты героев и изменённые иконки часто требуют выбора вручную.
- Проценты берутся из снимка **7.41d**, это общий винрейт, не шанс победы конкретной сборки.
- Игровой оверлей, вставка из буфера и автоматическое обновление статистики пока не реализованы.
- Затемнённые позиции не подписываются при низкой яркости.

## Данные

`data/windrun-7.41d.json`: 640 записей Windrun, 639 сопоставлены со справочником. Отрицательные ID — герои. У ID 8000 нет названия. В `assets/` находятся 639 PNG; источники и соответствия — в `data/icon-manifest.json`.

Для четырёх AD-вариантов Kez (1517–1520) используются иконки обычных версий, соответствие нужно проверять визуально. Повторно скачать недостающие иконки: `python3 scripts/download_icons.py` (Python 3.9+, без сторонних пакетов). Статистика импортирована вручную; импорт свежего ответа пока не реализован.

## Обработка без окна

```sh
python3 recognizer.py screenshot.png --output outputs/annotated.png
```

Рядом сохраняется JSON с предположениями, расстояниями и флагом `accepted`. Значения расстояний не являются вероятностями.
