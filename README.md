# Ability Draft Helper

Локальный помощник для драфта Dota 2 Ability Draft. Планируемая первая версия принимает скриншот и подписывает винрейты рядом с распознанными способностями.

## Текущее состояние

Подготовлены данные и эталонные изображения. Распознавание скриншотов, интерфейс и игровой оверлей пока не реализованы.

- `data/windrun-7.41d.json` — 640 записей статистики Windrun для патча 7.41d; 639 сопоставлены с названиями из справочника сайта.
- `assets/abilities/` и `assets/heroes/` — 639 PNG-изображений, загруженных с CDN Valve.
- `data/icon-manifest.json` — соответствия ID, локальных файлов и исходных URL, размеры и статус загрузки.
- `scripts/download_icons.py` — повторная загрузка недостающих иконок, существующие файлы используются из локального кэша. Требуется Python 3.9+ без дополнительных пакетов.

```sh
python3 scripts/download_icons.py
```

## Известные ограничения

Запись ID 8000 отсутствует в импортированном справочнике; её название и иконка неизвестны. Для четырёх AD-вариантов способностей Kez (1517–1520) взяты иконки обычных версий. Их соответствие игровому экрану нужно проверить при разработке распознавания.

`winrate` хранится как доля от 0 до 1. Это общий винрейт записи в выборке, а не вероятность победы конкретной сборки. Таблица содержит как способности, так и героев (отрицательные ID).

## Обновление статистики

Исходная статистика импортирована из вручную переданного ответа Windrun. Планируется ручной импорт свежего ответа примерно раз в неделю с локальным хранением данных. Автоматический импорт пока не реализован; загрузчик иконок использует снимок 7.41d.

## Источники

- Статистика и справочник: https://windrun.io/abilities
- Иконки: https://cdn.cloudflare.steamstatic.com/apps/dota2/images/dota_react/

Иконки Dota 2 принадлежат Valve; данные Windrun и изображения сохраняются с указанием источников. Этот репозиторий не заявляет авторство сторонних материалов.
